# 实施计划

更新日期：2026-11-26。本轮仅完成工程盘点与文档规划；P1–P4 尚未实施。本页是阶段状态与验收条件的统一入口。

## 目标与完成标准

将当前三源合并订阅逐步升级为有业务保护、可重复验证、固定候选试用与稳定回滚的规则工程。首轮以现有 Mihomo 与 AdGuard DNS 输出为范围，订阅路径和文件名保持兼容。

整体验收需同时满足：

- 不同来源重新带入受保护规则时，全局保护仍生效，并能解释来源和处理决定。
- 正常业务应通过、已确认广告应拦截；父子域例外、原生模式、IP 交叉均有边界用例。
- 自动检查或必要场景失败，不能更新稳定订阅；缺失设备验收不能被当作通过。
- 稳定版与已验收候选的规则哈希一致，源码、输入、策略、内核与记录可追溯。
- 回滚恢复旧产物并保留历史，线上可下载且可核对；客户端刷新限制有明确说明。

## P1：业务保护与来源归属

依赖：P0。范围：数据、规则处理与静态测试，不切换线上工作流。

- [ ] 记录基线快照、所有来源归属与原始规则位置，补可追溯的数据模型。
- [ ] 建立 `protection.json` 的版本化结构和严格校验，区分明确保护、广告例外及证据等级。
- [ ] 审查 Home DNS 保护候选；先核对 `gecko.snssdk.com`、`is.snssdk.com`、`tz.sec.xiaomi.com`，不直接宣布它们已经实机证实误拦。
- [ ] 合并后统一应用策略，记录剔除、保留、待审核及配置冲突；本地新增规则也受约束。
- [ ] 覆盖父域跨界、策略重叠、例外与放行冲突，以及来源重复带入的回归。
- [ ] 按实际职责逐步拆分单脚本，保留原有命令和离线复现行为，补完整源码快照导出。

验收：保护规则不因上游顺序改变而失效；确切广告例外可保留但不压过明确放行；无法处理的范围冲突明确失败；同输入可复现；现有三源格式语义不变。

## P2：风险报告与持续内核验证

依赖：P1。范围：验证入口、报告和 CI 验证任务，不自动晋升稳定订阅。

- [ ] 建立 `validation.json`，记录变化审核阈值与固定内核版本、下载哈希。
- [ ] 对照稳定基准输出规则和放行变化、匹配范围扩大、策略处理、来源证据及未完成项。
- [ ] 区分失败、待审核、未知和通过；新增关键字、模式、IP 段等风险逐项可定位。
- [ ] 建立域名/IP 场景清单与受控网络测试，所有必测项实际执行。
- [ ] 固化 Mihomo 和 AdGuard Home 启动、加载、匹配、A/AAAA 响应和资源清理。
- [ ] 输出可读报告及机器清单，测试离线、缺内核、超时、失败清理等路径。

验收：故意放入受保护业务误拦或宽泛规则时能失败/待审核；网络超时不被当作通过；相同候选与固定内核结果可复核；自动化测试不修改系统 DNS。

## P3：候选与稳定发布切换

依赖：P2。范围：发布脚本和工作流，首次写入前展示差异和迁移验证。

- [ ] 保存当前可回退稳定基线，建立候选内容标识、清单与长期不可变快照。
- [ ] 定时任务改为验证后发布候选，稳定 `dist` 不再被定时任务直接更新。
- [ ] 建立手动晋升：候选哈希、审核与验收记录、策略指纹、稳定基准和串行发布检查。
- [ ] 检查诊断失败、待审核、PR、无变化、首次发布、并发晋升和过期候选。
- [ ] 生成同版本固定 URL 的 Mihomo 示例，说明日常双文件更新的缓存限制。
- [ ] 提供线上核验及追加提交回滚，完成临时远端模拟和一次可恢复演练。

验收：试用过的产物直接晋升；候选生成后上游更新不会改变待晋升文件；旧基准候选不能覆盖新稳定版；PR 无发布权限；回滚不强推。

## P4：设备验收与首个受控稳定版

依赖：P3。该阶段需要用户指定测试设备、主要 App、必要功能和试用记录；缺这些信息不阻碍先做 P1–P3。

- [ ] 固定候选提交，在单设备完成登录、图片、正常播放和广告场景。
- [ ] 根据使用情况补充支付、推送、更新、Wi-Fi/移动网络及 DNS/代理路径测试。
- [ ] 对异常做窄域名放行对照，证实原因后补保护策略和回归。
- [ ] 完成约定观察窗口与全部必测场景，记录未测项及残余限制。
- [ ] 晋升首次完整验收版本，核对线上哈希、固定配置与客户端实际加载版本。

验收：报告绑定同一候选、设备与 App 版本，有明确场景结果；没有证据的功能不写已验证；失败反馈可追溯到修复和新候选。

## 阶段交付与暂缓范围

每阶段以可审查变更交付代码、配置、测试和文档；实现后再将相应任务勾选为完成。测试通过证据与外部环境验证分开记录，不以阶段结束为由自动宣称所有业务安全。

首轮暂缓管理后台、数据库、DNS 服务部署、更多规则格式、Lite/纯广告变体、全量公网域名扫描及自动学习误拦。解析失败就排除域名、域名含 `ad` 就认定为广告、试用时间到自动晋升，均不作为项目机制。
