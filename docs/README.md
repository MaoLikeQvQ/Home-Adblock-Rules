## 统一状态定义

- **已实现**：当前源码与工作流能够执行；不代表全部设备或业务已经验证。
- **历史验证**：在记录的输入、内核与环境上通过，不能代表自动更新后的所有规则版本。
- **待实施**：只有方案与验收条件；示例路径、字段、命令不能当作现有功能使用。
- **待业务确认**：需要使用场景或实机证据决定，不能通过文档约定自动认定为安全。

使用说明以实际源码与工作流为准；目标模块和配置以设计文档为准；任务完成状态只在实施计划维护。实现某项能力时，同次变更更新对应说明、测试证据和任务状态。
